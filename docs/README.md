# Design documentation

[← Main proposal](../README.md)

These pages expand the community proposal for a sustainable level-60 endgame. They describe desired behavior and testable design constraints, rather than existing game code or confirmed future features.

Decided directions through v0.2: permanent equipment with contextual bonuses; bonuses shared by approved raids in the same update; separate Normal/Veteran progression; Veteran prestige plus its own internal power track; cooperative settlement defense/recovery; finite procedural expeditions; separate prestige tracks without stats; and original playable identities subject to review. Point multipliers are prototypes; reward rates, rank thresholds, loot cadence, normalization profiles and final race/class selection remain open.

For editing and feedback conventions, see [CONTRIBUTING.md](../CONTRIBUTING.md). The [asset directory](../assets/README.md) documents illustrations, diagrams and their provenance.
