# Change history

## 0.1 — 2026-11-10

- Established the public repository as the detailed home of the community proposal.
- Consolidated permanent equipment with update-wide, difficulty-scoped raid bonuses and independent Normal/Veteran progression.
- Documented tactical Heroics, keyless Challenge Modes, elite regions, territorial PvP, professions and other optional activities.
- Added conceptual technical rules, acceptance cases, trade-offs, a pilot roadmap and an official-source register.
- Added original cover art, editable explanatory diagrams, contribution guidance and an unpublished forum summary draft.

This version describes a design proposal. It does not ship gameplay systems or represent an official roadmap.
